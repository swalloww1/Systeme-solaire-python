 Système Solaire Interactif

Une simulation 2D du Système Solaire développée en Python à l'aide de la bibliothèque Pygame. 

-fonctionalité:

  Physique Réelle (Lois de Kepler) : Les orbites ne sont pas des cercles mais des ellipses, prenant en compte l'excentricité de chaque planète. Leurs vitesses s'adaptent selon leur position (résolution de l'équation de Kepler par la méthode de Newton-Raphson).

  Interface Graphique: Un panneau de contrôle cliquable permettant de piloter la simulation.

  Mode Focus: Possibilité de cibler une planète pour la suivre, avec affichage de sa distance par rapport au Soleil en Unités Astronomiques (UA).

  Gestion du Temps : Accélération, ralentissement, fonction Pause/Play et affichage d'une date simulée.

-Technique

  Langage : Python 3

  Bibliothèque graphique : Pygame

  Mathématiques : Modules natifs math et random
